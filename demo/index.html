Hyperparameters

Evolution

Keep successful candidates, cross their weights, and add random mutations.

Rates are fractions: 0.14 means 14%. Mutation scale drops to its final value after 60% of the selected training length. A same-move run also has a safety limit of 1,000 generations.

DQN

Learn Q values from replayed experiences using Adam and a separate target network.

A larger learning rate changes weights faster. Exploration is the chance of a random move; it decreases linearly. Higher γ values place more weight on future rewards.

Shared environment

Evolution is validated after every complete generation in per-method mode. DQN and same-move runs use the move interval. Validation uses eight fixed maps with exploration off; it never updates weights.
